## 📝 Tasks Completed (1-Month Tier)
As part of the 1-month internship requirements, the following tasks have been completed:

1. **Personal Portfolio Website**
   - Built a fully responsive personal portfolio using HTML, CSS, and basic JavaScript.
   - Included core sections: **About Me, Skills, Projects, and Contact**.
   - Optimized layout for both desktop and mobile viewports.

2. **Responsive Landing Page**
   - Designed a clean, modern landing page for a sample product/service.
   - Utilized **CSS Flexbox/Grid** for organized alignment.
   - Structured sections including a header, hero banner, features breakdown, and footer.

3. **Simple Calculator Web App**
   - Developed a functional calculator to handle basic arithmetic operations.
   - Designed a realistic button keypad layout.
   - Implemented error handling for edge cases (e.g., division by zero) with clean, well-commented JavaScript code.
