1. What is Data Analytics?

Data Analytics is the process of examining data to find useful information, patterns and insights.

Where is Data Analytics used?

  • Business decision making
  • Marketing
  • Finance
  • Healthcare
  • Education
  • Technology

2. Types of Data

Data can come in different forms depending on what we want to analyze.

Structured Data

Data organized in rows and columns, such as an Excel spreadsheet or database.

Unstructured Data

Data such as images, videos, audio and text that does not follow a fixed table format.

3. Data Cleaning

Data collected from the real world can contain missing values, duplicate records or incorrect data.

Common cleaning steps

  • Remove duplicate records
  • Handle missing values
  • Correct incorrect values
  • Convert data into suitable formats
  • Check for unusual values

4. Python for Data Analytics

Python is widely used for data analysis. Libraries such as Pandas and NumPy make data processing easier.

Example using Pandas

import pandas as pd

data = pd.read_csv("students.csv")

print(data.head())

The read_csv() function can be used to load data from a CSV file.

5. Data Visualization

Data visualization means representing data using charts and graphs so that patterns can be understood easily.

Common charts

  • Bar Chart
  • Line Chart
  • Pie Chart
  • Scatter Plot
  • Histogram

6. Simple Data Analysis Example

Suppose we have the marks of five students. We can calculate their average using Python.

marks = [80, 75, 90, 85, 70]

average = sum(marks) / len(marks)

print("Average:", average)

This program calculates the average marks of the students.
