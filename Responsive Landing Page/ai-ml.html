1. What is Artificial Intelligence?

Artificial Intelligence, or AI, is the ability of a computer system to perform tasks that normally require human intelligence.

Examples of AI

  • Voice assistants
  • Recommendation systems
  • Chatbots
  • Image recognition
  • Self-driving technology

2. What is Machine Learning?

Machine Learning is a branch of AI where computers learn patterns from data and use those patterns to make predictions or decisions.

Simple idea

Data → Learning → Model → Prediction

For example, a model can learn from previous house prices and predict the price of a new house.

3. Types of Machine Learning

Supervised Learning

The model learns using data that already has correct answers or labels.

Example: Predicting whether an email is spam.

Unsupervised Learning

The model finds patterns or groups in data without predefined labels.

Example: Grouping customers based on their behavior.

Reinforcement Learning

An agent learns by interacting with an environment and receiving rewards or penalties.

4. Data & Features

Data is the foundation of Machine Learning. A model learns patterns from the data provided to it.

What is a Feature?

A feature is an input value used by a Machine Learning model to make a prediction.

Age = 20
Study Hours = 5
Attendance = 90%

These values can be used as features to predict a student's performance.

5. Training a Machine Learning Model

Training means allowing a Machine Learning algorithm to learn patterns from a dataset.

Basic ML workflow

  • Collect data
  • Clean the data
  • Select features
  • Split the data
  • Train the model
  • Test the model
  • Make predictions

6. Simple Machine Learning Example

Here is a simple example using Python and Linear Regression.

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)

prediction = model.predict(X_test)

The model learns the relationship between the input data and the target value and then uses that relationship to make predictions.
