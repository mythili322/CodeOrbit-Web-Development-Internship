1. Introduction to Python

Python is a simple and powerful programming language. It is widely used in Web Development, Artificial Intelligence, Machine Learning and Data Analytics.

Why learn Python?

  • Easy to understand
  • Beginner friendly
  • Used in AI and Machine Learning
  • Large number of libraries

First Python Program

print("Hello, World!")

The print() function displays information on the screen.

2. Variables & Data Types

A variable is used to store information in a program.

name = "Mythili"
age = 20
marks = 85.5

Common Data Types

  • String → "Hello"
  • Integer → 20
  • Float → 85.5
  • Boolean → True / False

3. Conditions

Conditions allow a program to make decisions.

age = 20

if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")

The if statement checks a condition. If it is true, the first block runs.

4. Loops

Loops are used when we want to repeat a task multiple times.

For Loop

for i in range(5):
    print(i)

This program prints numbers from 0 to 4.

5. Functions

A function is a reusable block of code that performs a specific task.

def greet(name):
    print("Hello", name)

greet("Mythili")

Functions help us organize our programs and avoid writing the same code repeatedly.

6. Practice Program

Let's create a simple program that checks whether a number is positive or negative.

number = int(input("Enter a number: "))

if number >= 0:
    print("Positive number")
else:
    print("Negative number")
