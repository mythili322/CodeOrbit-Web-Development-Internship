# Responsive Landing Page

## Description

A responsive AI learning platform landing page created using HTML, CSS and JavaScript. The website presents AIHub, a fictional AI learning platform, with a clean and user-friendly interface.

## Features

- Responsive design for desktop, tablet and mobile devices
- Navigation bar
- Hero section with call-to-action buttons
- Courses section
- Features section
- Learning statistics section
- Call-to-action section
- Footer section
- Separate course pages for Python, AI & Machine Learning and Data Analytics
- Responsive layout using CSS Grid and Flexbox

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox

## Project Sections

- Home
- Courses
- Features
- Statistics
- Call to Action
- Footer

## Course Pages

- Python Programming
- AI & Machine Learning
- Data Analytics

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
