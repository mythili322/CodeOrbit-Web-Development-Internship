# Simple Calculator Web App

## Description

A simple and responsive calculator web application created using HTML, CSS and JavaScript. The website provides basic arithmetic operations through a clean and user-friendly calculator interface.

## Features

- Responsive design for desktop, tablet and mobile devices
- Clean calculator-style interface
- Addition operation
- Subtraction operation
- Multiplication operation
- Division operation
- Decimal number support
- Clear (AC) button
- Delete (DEL) button
- Division-by-zero error handling
- Interactive calculator buttons
- Responsive layout using CSS Grid

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Responsive Design

## Calculator Operations

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons to perform arithmetic operations.
